# Student Placement Prediction System

## About the Project
The Student Placement Prediction System is a Machine Learning project developed using Python. It predicts whether a student is likely to get placed based on academic performance and other skills.

## Features
- Predicts student placement status.
- Uses student academic and skill-related information.
- Uses Machine Learning classification.
- Displays placement prediction probabilities.

## Input Features
- CGPA
- Internships
- Projects
- Aptitude Test Score
- Soft Skills Rating
- Placement Training

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## How to Run
1. Install Python.
2. Install the required libraries.
3. Run the Python project file.
